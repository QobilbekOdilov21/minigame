# 🎮 SysOne Academy — MiniGame

O‘quvchilar bilan bir vaqtda o‘ynash uchun bepul, oddiy HTML multiplayer o‘yin.

## Boshlash

1. GitHub’da **Settings → Pages → Build and deployment** bo‘limini oching.
2. **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** ni tanlang va **Save** bosing.
3. GitHub Pages manzili: https://qobilbekodilov21.github.io/minigame/
4. Saytni o‘qituvchi ochib **Xona yaratish** tugmasini bosadi.
5. **Havolani nusxalash** tugmasidan Telegram guruhiga link yuboradi.
6. O‘quvchilar havola orqali kirib, ismini yozib qo‘shiladi.

## O‘yin rejimlari

- 🧠 Informatika viktorinasi — har to‘g‘ri javob uchun 10 ball
- ⭐ 90 soniyalik arena — yulduz uchun 2 ball
- 🔴 🔵 🟢 2 yoki 3 jamoa va umumiy natijalar
- 📱 Telefon hamda kompyuterdan boshqarish

Barcha o‘yin kodi `index.html` ichida joylashgan. HTML/CSS/JavaScript, PeerJS Cloud (WebRTC signaling) ishlatiladi. Maxsus backend va API kaliti talab qilinmaydi.

**Muhim:** o‘qituvchining brauzeri xona davomida ochiq turishi shart. Internet va PeerJS xizmatiga ulanish kerak. 20 o‘quvchigacha mo‘ljallangan; ko‘p qurilmalarda ulanish barqarorligi tarmoqqa bog‘liq. Sinfda foydalanishdan oldin bir nechta qurilmada tekshiring.

O‘quvchilarga familiyasi yoki shaxsiy ma’lumotlarini emas, ismi yoki taxallusini kiritishni tavsiya eting.
